# ClipCopy

register: brand

ClipCopy is an independent native macOS text clipboard history utility. Select a recent entry in the menu bar, then paste with Cmd+V. Local encrypted history, configurable count limit, ignored apps, pause and optional login start. No account, cloud sync, telemetry, AI processing, automatic paste or supported global hotkey. The public beta is Apple Silicon, macOS 15.4+, ad-hoc signed and not notarized. User clipboard contents and keys never belong in this repository.

Landing page audience: Mac users switching between documents, websites and messages who need to reuse copied text. Tone: clear, quiet, useful. Primary action: download the actual beta release; secondary: read source/limitations. Reference: Markdown Magic static DE/EN site, read-only. Own product screenshots with synthetic examples only.
