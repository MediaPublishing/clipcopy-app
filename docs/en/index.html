Local history

Your history.
On your Mac.

ClipCopy encrypts text history locally. The key stays in macOS Keychain. No account, cloud sync or telemetry.

  • Choose storage and display limits. The default is 1,000 entries.
  • Exclude apps from recording and pause when needed.
  • No time-based expiry. The count limit removes the oldest entries.

ClipCopy Beta

Before you get started.

What does the beta store?

Text from the clipboard. Rich text is captured as plain text when the source offers a text representation. Images, files, cloud sync, automatic pasting and a global keyboard shortcut are not included.

How do I enable recording?

Open Preferences… → General and enable Record clipboard history. Allow clipboard access in macOS if prompted. If needed, choose persistent clipboard access under System Settings → Privacy & Security → Clipboard, then enable recording again. Recording begins with your next new copy. Quit CopyClip first; running it alongside ClipCopy prevents recording from starting.

Are sensitive copies always protected?

Known password managers and copies marked as confidential are skipped. ClipCopy cannot detect every sensitive text. Pause recording or exclude an app before copying confidential information there.

What should I know about the beta?

Apple Silicon and macOS 15.4 or newer. The beta is ad-hoc signed, has no Apple Developer ID signature and is not notarized by Apple. Updates are manual. A lost local Keychain key cannot be automatically recovered.

Is this CopyClip?

No. ClipCopy is independently implemented and is not affiliated with FIPLAB or CopyClip. This public beta does not import other clipboard histories. Some originally modelled vendor menu items remain disabled.

Release notes & checksum

Getting started with the beta.

  1. Download and extract the ZIP, then move ClipCopy.app to Applications.
  2. Open ClipCopy. If macOS blocks the beta, review Privacy & Security and only choose Open Anyway if you trust the source.
  3. Enable recording in Preferences… and grant clipboard access. Launch at login is optional.
